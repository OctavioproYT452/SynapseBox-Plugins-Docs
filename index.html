⚠️ Antes de seguir: crea tu archivo .env

Para subir plugins a la comunidad, SynapseBox necesita un token de acceso guardado en un archivo llamado .env. Si no lo haces, la subida fallará.

  1. Pide el token en un ticket del Discord oficial.
  2. Crea el archivo .env en la carpeta de SynapseBox y añade PLUGINS_GITHUB_TOKEN=tu_token.
  3. Reinicia SynapseBox.

Te lo explicamos paso a paso justo después de cerrar este aviso.

0Obligatorio: crea el archivo .env

Es el único paso que no puedes saltarte si quieres subir plugins. Para descargar e instalar no hace falta.

🚫 Sin este paso, subir un plugin dará error.SynapseBox necesita un permiso (token) para poder enviar tu plugin al repositorio oficial.
  1. Pide tu token
    Entra al servidor oficial de Discord, abre un ticket en la sección de soporte y pide el token de plugins. Te lo daremos por privado.
  2. Abre la carpeta de SynapseBox
    Es la misma donde está package.json y server.js. Si ya tienes un archivo .env, ábrelo. Si no, crea uno nuevo (no .env.txt; el nombre empieza por punto).
  3. Escribe esta línea (cambia lo de la derecha por tu token): 
    PLUGINS_GITHUB_TOKEN=PEGA_AQUI_TU_TOKEN
    Sin espacios, sin comillas y sin dejar nada detrás del token.
  4. Guarda el archivo y reinicia SynapseBox
    Los cambios del .env solo se leen al arrancar.
  5. Comprueba que funciona
    Entra en Admin → Plugins → Subir plugin. Si al subir no te da error de permisos, está bien configurado.
🔒

Nunca lo compartas

El token es como una contraseña. No lo publiques, no lo pongas en capturas ni lo subas a ningún repositorio.

🙈

No subas el .env

El archivo .env ya está en el .gitignore de SynapseBox: déjalo así.

🎯

Acceso limitado

El token solo sirve para el repositorio de plugins, nada más.

🆘

¿Se filtró?

Avisa en un ticket del Discord para que lo revoquen y te den otro.

Otras variables opcionalesCambia PLUGINS_REPO=usuario/repositorio si usas otro repositorio. Los plugins que solo descargas no necesitan ninguna.

1Tu primer plugin en 5 minutos

Vamos a crear un plugin que muestra un saludo en la pantalla. No necesitas saber mucho: copia y pega.

  1. Crea una carpeta dentro de data/plugins/ llamada mi-saludo.
    SynapseBox/
    └── data/
       └── plugins/
          └── mi-saludo/ ← la creas tú
  2. Dentro, crea plugin.json (la “tarjeta de identidad” del plugin): 
    {
  "id": "mi-saludo",
  "title": "Mi saludo",
  "version": "1.0.0",
  "category": "Utilidades",
  "description": "Muestra un saludo al abrir el panel.",
  "client": "client.js"
}
  3. Crea client.js (lo que verá el usuario en el navegador): 
    SynapseBox.ready(() => {
  SynapseBox.toast("¡Hola desde mi primer plugin! 👋");
});
  4. Actívalo
    Ve a Admin → Plugins → Instalados, busca “Mi saludo” y enciende el interruptor.
  5. ¡Míralo!
    Recarga el panel: aparece el aviso. Apaga el interruptor y desaparece. Así de simple.
🎉 Ya sabes lo básicoUn plugin es una carpeta con un plugin.json y uno o más archivos de código. Ahora veamos qué piezas puedes usar.

2Las 3 piezas de un plugin

Todas son opcionales: usa solo las que necesites.

🖥️

server.js

El cerebro. Corre en el servidor (Node.js). Para crear direcciones nuevas, guardar datos, reemplazar iconos o cambiar cómo responde SynapseBox.

🌐

client.js

Lo que se ve y se toca. Corre en el navegador. Para botones, avisos, atajos de teclado, cambiar textos.

🎨

style.css

La pintura. Solo estilos: colores, tamaños, ocultar o mover cosas.

mi-plugin/
├── plugin.json ← obligatorio: nombre, versión, descripción
├── server.js ← opcional: parte del servidor
├── client.js ← opcional: parte del navegador
├── style.css ← opcional: estilos
└── images/ ← portada y capturas (1 a 5)

El plugin.json, campo por campo

Campo¿Qué pongo?Ejemplo
idNombre corto sin espacios ni mayúsculas. Igual que la carpeta.mi-saludo
titleEl nombre que verá la gente.Mi saludo
versionTres números. Súbela cada vez que mejores el plugin.1.0.0 → 1.1.0
categoryGrupo donde aparecerá.Apariencia, Utilidades…
descriptionQué hace, en una o dos frases.Muestra un saludo…
server · client · styleNombre de cada archivo que uses. Quita los que no uses."client": "client.js"

Ejemplos rápidos

🎨 Cambiar un color (solo style.css)
:root { --accent: #ff4d94 !important; }
Pon "style": "style.css" en el plugin.json.
🖼️ Cambiar un icono o imagen (server.js)
module.exports = api => {
  api.serveFile("/favicon.svg", "mi-icono.svg");
};
Pon el archivo mi-icono.svg junto al server.js. Cuando alguien pida /favicon.svg, recibirá el tuyo.
🛣️ Crear una dirección nueva (server.js)
module.exports = api => {
  api.get("/api/plugins/mi-plugin/hora", (req, res) => {
    res.json({ hora: new Date().toISOString() });
  });
};
Visita /api/plugins/mi-plugin/hora y verás la hora.
💾 Guardar datos (server.js)
module.exports = api => {
  api.post("/api/plugins/contador/sumar", (req, res) => {
    const n = api.data.read("contador", { n: 0 }).n + 1;
    api.data.write("contador", { n });
    res.json({ n });
  });
};
🔐 Solo para administradores
api.get("/api/plugins/mi-plugin/secreto", (req, res) => {
  if (!req.user?.is_admin) return res.status(403).json({ error: "Solo administradores" });
  res.json({ ok: true });
});
🛑 Cambiar cómo responde SynapseBox (middleware)
api.use((req, res, next) => {
  if (req.path === "/prohibido") return res.status(403).send("No");
  next(); // ¡no olvides next()! sin él, la petición se queda parada
});
🧱 Añadir un botón nuevo (client.js)
SynapseBox.ready(() => {
  const b = document.createElement("button");
  b.className = "btn"; b.textContent = "Saludar";
  b.onclick = () => SynapseBox.toast("¡Hola!");
  document.body.append(b);
});
⏱️ Tarea que se repite (acordarse de limpiar)
let t;
module.exports = {
  activate(api) { t = setInterval(() => api.log("tic"), 60000); },
  deactivate()  { clearInterval(t); }   // se ejecuta al apagar el plugin
};

3Referencia rápida

Para cuando ya quieras hacer cosas más grandes. No hace falta memorizarla.

En server.js recibes api

HerramientaSirve para
api.get / post / put / delete(ruta, fn)Crear direcciones. Si ya existe, la tuya la sustituye.
api.use(fn)Revisar o cambiar todas las peticiones.
api.serveFile(url, archivo)Responder una dirección con un archivo tuyo (iconos, imágenes).
api.serveDir(url, carpeta)Publicar una carpeta entera.
api.transformHtml(fn)Modificar el HTML de cualquier página antes de enviarla.
api.inject.head / bodyAñadir trozos de HTML a todas las páginas.
api.data.read / writeGuardar y leer tus propios datos.
api.dbBase de datos de SynapseBox (get, all, run).
api.core("ruta")Usar cualquier módulo interno de SynapseBox.
api.on / emitEventos: server:start y plugin:enabled (y los tuyos).
api.log(...)Escribir en la consola con el nombre de tu plugin.

Dentro de una ruta: req.user es la persona con sesión (o vacío) y req.user.is_admin dice si es administrador.

En client.js tienes SynapseBox

HerramientaSirve para
SynapseBox.ready(fn)Ejecutar cuando la página está lista.
SynapseBox.pageEn qué página estás (panel, admin/index…).
SynapseBox.toast(texto)Aviso emergente.
SynapseBox.api(url, datos?)Hablar con el servidor (devuelve JSON).
SynapseBox.css(texto)Añadir estilos desde código.
SynapseBox.session()Saber quién ha iniciado sesión.

Ciclo de vida

🟢 Activar
se ejecuta activate→⚙️ Funciona

4Subir tu plugin a la comunidad

¿Hiciste el Paso 0?Necesitas el .env con PLUGINS_GITHUB_TOKEN. Volver a verlo
  1. Ve a Admin → Plugins → Subir plugin.
  2. Rellena todo lo obligatorio: Título Descripción Categoría 1 a 5 imágenes Archivo(s). La versión es opcional (por defecto 1.0.0).
  3. Pulsa Subir al repositorio. SynapseBox hace el trabajo de Git por ti.
  4. Tu plugin queda en el repositorio de plugins y aparece en la pestaña Repositorio para todos.

Cómo queda ordenado

SynapseBox-Puglins/
└── 📁 Utilidades ← categoría
   └── 📁 mi-saludo ← tu plugin
      ├── plugin.json ← versión, título, descripción…
      ├── 📁 images ← tus imágenes
      └── client.js ← tus archivos

Para actualizar un plugin, súbelo con el mismo título y una versión mayor. Para descargar uno, ve a la pestaña Repositorio y pulsa Descargar; luego actívalo en Instalados.

LímiteValor
Imágenesde 1 a 5 (PNG, JPG, GIF, WebP o SVG)
Tamaño por archivo5 MB
Archivos por pluginhasta 20

5Buenas prácticas y seguridad

✅

Comprueba quién es

Usa req.user y is_admin antes de dar datos o permitir cambios.

🧼

No te fíes de lo que llega

Valida todo lo que venga en req.body y req.query.

🏷️

Rutas con tu nombre

Empieza por /api/plugins/tu-id/… para no pisar nada sin querer.

🧹

Limpia al apagar

Detén temporizadores en deactivate.

🎨

Usa las variables del tema

var(--card), var(--accent), var(--text)… así respetas los temas.

🤫

Cero secretos en el plugin

Nada de contraseñas ni tokens dentro de tus archivos: el repositorio es público.

6¿Algo no funciona?

Al subir me dice que no tengo permiso o falla GitRevisa el Paso 0: el archivo debe llamarse exactamente .env, estar junto a package.json, contener PLUGINS_GITHUB_TOKEN=… sin espacios ni comillas, y SynapseBox debe haberse reiniciado después. También necesitas tener git instalado. Si sigue fallando, abre un ticket en el Discord.
Mi plugin no aparece en “Instalados”La carpeta debe estar en data/plugins/, llamarse igual que el id y tener un plugin.json válido (revisa comas y comillas).
Lo activo y no pasa nadaRecarga la página con Ctrl+F5. Mira la consola del servidor: si hay un error en tu server.js, saldrá ahí con el nombre del plugin.
Cambié el código y no se notaApaga y vuelve a encender el plugin: se recarga sin reiniciar el servidor. En el navegador, usa Ctrl+F5.
Mi ruta nueva da “No encontrado”Comprueba que el plugin está activado y que la dirección empieza igual que en tu código. Si usas api.use, no olvides llamar a next().
Dónde pido ayudaEn un ticket del servidor oficial de Discord.
